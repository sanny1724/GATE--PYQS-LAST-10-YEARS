Welcome to the ultimate **GATE Computer Science & Information Technology (CSE/IT)** subject-wise Previous Year Question (PYQ) repository!

This repository contains meticulously verified, categorized, and beautifully formatted PDFs for all GATE CSE questions asked between **2016 and 2025** across **16 exam sessions** (550 pages of official GATE paper sets).

---

## 🌟 Key Features

- **100% Subject Categorization Accuracy**: All 895 questions have been audited and sorted into their precise academic subject domains (e.g., separating Calculus integrals from DBMS or Probability).
- **Complete Question Statements & Options**: Includes full problem statements, figure descriptions, and options `(A)`, `(B)`, `(C)`, and `(D)` for Multiple Choice Questions (MCQ) and Multiple Select Questions (MSQ), as well as Numerical Answer Type (NAT) prompts.
- **Clean Matrix & Vector Formatting**: Raw PDF extraction artifacts (broken bracket glyphs like `⎡`, `⎢`, `⎣`) have been cleaned and aligned into clear rectangular block structures for $2\times2$, $3\times3$, and vector representations.
- **Mathematical Symbol Integrity**: Fully preserves mathematical, logical, and set-theoretic symbols ($\rightarrow, \times, \int, \in, \lambda, \det, \land, \lor$, etc.) using custom vector font rendering.
- **Watermarked**: Every page features the custom top-right watermark **`@TECHNITH`**.

## ℹ️ Question Meta Header Format

Each question in the subject PDFs contains a metadata header formatted as follows:

```
Question X of Y  |  GATE <Year> <Set>  |  Q.<Original_Number> (<Section>)
[ Type: MCQ / MSQ / NAT | Marks: Correct / Negative ]
```

- **Subject Index (`Question X of Y`)**: Shows the question number within the subject PDF.
- **Original Reference (`Q.<Original_Number>`)**: References the exact original question number in the official GATE question paper for easy cross-verification.
